# QTG Studio

The current application is in [QTG_STUDIO/](QTG_STUDIO/). See its [development guide](QTG_STUDIO/README_GITHUB.md) for setup, tests, builds and Test settings password configuration.

From a Windows development environment with dependencies installed, run `python main.py` inside `QTG_STUDIO/`.

The application may connect to Prepar3D on startup. Supervise simulator and hardware operations. The experimental throttle-only engine sequence is not integrated into the GUI.

The previous workspace is available in earlier commits.
